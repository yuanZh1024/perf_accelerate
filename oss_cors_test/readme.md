【补充】CORS理解

Origin（当前网页：协议 + 主机 + 端口） 和 目标请求 URL（协议 + 主机 + 端口）三者不全相同 → 就是跨域。**

> 页面 Origin：`A协议://A主机:A端口` 要访问的接口 URL：`B协议://B主机:B端口`
>
> 三个要素**全部一模一样 = 同源**；只要任意一个不一样 = 跨域。 路径、查询参数、# 锚点，**不参与判断，无关**。

举你的实验例子

网页页面 Origin：`http://127.0.0.1:5500` 请求目标 URL：`http://192.168.184.128:9002/cors-demo-bucket`

- 协议：都是 http ✔
- 主机：`127.0.0.1` vs `192.168.184.128` 不一样
- 端口：5500 vs 9002 不一样 👉 要素不一致 → **跨域**

浏览器发起这个跨域请求，**自动带上 Origin 请求头**： `Origin: http://127.0.0.1:5500`
